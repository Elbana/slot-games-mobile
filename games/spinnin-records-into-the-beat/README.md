# Spinnin' Records Into the Beat — PixiJS Mobile Client

Native PixiJS mobile client ported from `slot-games-client`.

> Native beat art/client TBD — currently uses Stadium-style reel client + math as a playable placeholder.


## Run

```powershell
cd games/undefined
npm install
npm run dev
```

Open **http://localhost:5183/**

## Assets

Assets are copied from `slot-games-client/public/assets/football-gold/`.
If missing, run asset fetch scripts in `slot-games-client` first.
