# Temple of Three — PixiJS Mobile Client

Native PixiJS mobile client ported from `slot-games-client`.

## Run

```powershell
cd games/undefined
npm install
npm run dev
```

Open **http://localhost:5182/**

## Assets

Assets are copied from `slot-games-client/public/assets/egypt-treasures/`.
If missing, run asset fetch scripts in `slot-games-client` first.
