# Games Mobile

Standalone PixiJS/Vite project for the visual reconstruction of the first mobile slot game.

The initial scaffold contains only the browser renderer. The visual milestone will add the rights-cleared game assets, responsive 6x5 composition, and scripted demo animations. It intentionally does not include the legacy client bundle, WebSocket protocol, server, or game math.

## Run

```powershell
cd D:\projects\slot\games-mobile
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite. Build with `npm.cmd run build`.
